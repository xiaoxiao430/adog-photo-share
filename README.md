# 爱多格·三图与文案套装

顾客一次领取固定的三张照片和一段参考文案。点击“换一套”时，图片和文案一起切换；照片、文案与原有使用记录存放在Mac Studio。

- 管理后台：<https://jmryqyx.cn/aidog-photos/admin>
- 二维码海报：<https://jmryqyx.cn/aidog-photos/qr-poster.png>
- GitHub源码：<https://github.com/xiaoxiao430/adog-photo-share>
- GitHub分享入口：<https://xiaoxiao430.github.io/adog-photo-share/>

## 顾客使用

进入后直接显示一套三图。下载按钮下方是对应文案，点击“复制文案”取得全文；长文可以展开查看，收起预览不会截断复制内容。复制和浏览不消耗库存。

点击下载时才锁定这套三图，不会混入另一套图片；其他人已经领取时，页面会换到另一套完整图文并提醒重新复制。支持的手机可打开系统图片分享/保存面板；浏览器丢失点击激活时，同位置再点“保存这3张”。不支持时显示完整三图和逐张下载，保存后由本人确认。取消面板会释放未使用的锁定。

系统交付或本人确认后，同组三图记录相同使用时间，之后不再分给其他顾客。同一顾客重复保存原套不重复扣库。系统返回不能证明已写入手机相册，微信、iPhone和安卓真机相册尚未实测；本人已选择暂不连接手机，先完成网站升级。

## 后台整套上传

用用户指定的默认管理密码登录，无需用户名。每次必须同时提交正好3张不同照片和1段非空文案：JPG、PNG、WebP，每张最多12MB，整套最多36MB；文案1至1000字，名称选填、最多80字。可以粘贴文字或导入UTF-8 TXT。

未选满3张、缺少文案或图片无效时，前后端都禁止保存，数据库不会留下半套。整套使用稳定上传编号，超时重试不会重复入库；已配套的照片不能再拼入另一套。旧版逐张上传接口已关闭。

后台按套展示三图、文案、状态和北京时间使用日期。仅未领取的套装可编辑文案或删除；领取中和已使用内容只读。下载准备时保存文案快照，历史领取不跟随之后的改稿变化。

## 初始15套与历史记录

现有45张图整理为15套，并按现有素材主题配15段92至105字的参考文字。迁移前3张已使用照片仍按原时间保留为1套已用记录，其余42张组成14套可领取内容，已用图片没有恢复。

文案主题为到店照护、洗护、日常整理、咨询、体检、驱虫、绝育和疫苗等。未核实当前有效套餐名、价格、具体包含项目或有效期，因此没有填写这些信息，也没有虚构顾客消费、诊疗结果或疗效。AI示例图片和复制正文均保留AI配图说明，顾客可按真实体验调整。

公开参考文案在`content/package-copy.json`，不含线上图片ID或使用记录。私有迁移映射存储在本机`.local/initial-packages.json`和Studio受保护配置目录，不进入GitHub；数据库只执行一次初始配套，原图、缩略图、照片原字段和历史批次保持。

## 性能与部署

首屏只加载三张480px JPEG缩略图，原始图片在下载或查看大图时按需读取并复用。微软雅黑主子集约183KB，覆盖全部界面、素材名称及初始15段文案；完整字体保留为精确字形范围后备。

上一性能版同环境冷加载资源21MB降至0.51MB，套装升级继续保留小图与单字体首屏策略。首页Logo和平台图标使用适配屏幕的小尺寸PNG，二维码及下载原图保持不变；静态HTML/JS/CSS按浏览器支持启用gzip和ETag复用，API及私有照片仍禁止公共缓存。旧保存记录同步失败时先显示三图与文案，保留原记录供重试；同步确认前不领取另一套。45张原图和使用记录存Mac Studio，GitHub仅保存程序、公开文案、6张公开示例与分享入口；实际图库和私有配置不入库。GitHub Pages使用`main /docs`并跳转到同域应用。

`server.py`使用Python标准库、SQLite和私有图片文件，仅监听127.0.0.1。Mac Studio通过系统sips在上传时一次性生成缩略图，图片GET不转换。运行配置和密码哈希在私有文件，浏览器使用HttpOnly会话Cookie，写操作校验同源。

`python3 scripts/deploy.py`默认只检查，`--deploy`正式发布；先停止本工具、完整备份数据和配置，在离线状态初始化并逐列核对旧记录及原图/缩略图SHA，通过后才启动服务。新结构声明`PHOTO_SCHEMA_VERSION = 3`，不允许回退到会拆散图片的Flow2程序。初始配套文件由`scripts/deploy-stage-packages.py`安全暂存。

历史`scripts/seed-demo.py`和`import-library.py`仅保留只读素材盘点，旧散图上传标志拒绝写库。新增内容请使用后台整套表单。

验证：`python3 -m unittest discover -s tests -v`运行隔离成套HTTP检查；`tests/packages-browser.mjs`在专用本地套装QA实例验证真实表单、完整复制与下载流程，不向生产提交测试图片。部署与回退见`output/deploy说明.md`；二维码可编辑源在`assets/二维码/`。

微信扫码若显示“已停止访问”，需先取得微信提示原文，按[腾讯客服的恢复访问流程](https://kf.qq.com/faq/170118UnqeUZ170118mUb6fu.html)处理；外网HTTP200或模拟微信UA不能证明微信已放行，不以更换域名替代排查。
