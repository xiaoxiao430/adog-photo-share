# 爱多格·照片领取与管理

独立的三平台照片工具：顾客领取一组三张照片，再打开美团、大众点评或抖音；门店后台批量上传并查看照片使用时间。复用原“爱多格三平台扫码分享”的品牌、字体和门店链接，使用独立图库。

线上图库已补至45张现有宠物示例图，没有再生成新图片；仓库附其中6张公开示例。示例图明确标记，使用后退出后续领取。这些图片不是真实顾客或诊疗记录，后台可继续批量上传自己的照片。

## 使用

管理后台输入用户指定的默认管理密码即可登录，没有用户名。一次可选择多张JPG、PNG或WebP照片，逐张上传，每张最多12MB；相同文件自动跳过，不会因重新上传已用照片恢复库存。至少准备三张可用照片才能领取完整一组。图片无需预先手工分组。

后台显示全部、可领取、领取中和已使用照片，使用日期按北京时间显示。已使用照片保留原记录，不能删除或一键恢复到可用。三个平台的门店链接可在后台修改；美团、点评沿用原项目的门店分享链接，抖音暂为平台首页，取得正式门店链接后可替换。

顾客无需登录。支持多图系统分享的手机可一键打开系统保存面板；在面板中选择保存图片。不支持的浏览器显示三张原图及逐张下载，保存后点击“我已保存这3张”。照片不是ZIP文件，网页不会自动操作平台发布。

## 照片分配与记录

每组固定三张。浏览和换组不独占图库，也不写使用日期；连续换组优先展示尚未看过的可用照片。点击下载后，后端才在事务内锁定完整三张；预览已被他人领取时会自动换成新的三张。多个顾客并发下载取得互不重叠的组。系统交付完成或本人确认保存时，三张照片一起写入相同使用时间并退出后续候选；取消或关闭保存面板释放未使用锁定。同一顾客再次保存原组不再扣库。记录方式不表示已在平台发布。

纯预览记录有效15分钟，不影响其他访客看图；点击下载后锁定5分钟，保存面板打开时续期。空库页在前台每8秒重试，上传新图后自动恢复。客户端阻止过期交付，提交失败保留待同步记录。旧页面会收到刷新提示，不能绕过新版下载锁定。现网旧的六张纯浏览预留已释放，已使用照片和日期保持。

部分浏览器会在网络准备后丢失系统分享所需的点击激活，此时原位置显示“保存这3张”，再次点击即可打开系统面板；不支持文件分享时提供完整三图和逐张下载。不把浏览或文件预取记为保存完成。

系统分享的返回值只说明系统接收了文件，不能验证相册最终写入。真机微信、iPhone及安卓的保存入口仍需各设备实际确认。依据：[Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)。

## 程序与部署

`server.py` 使用Python标准库、SQLite与私有图片文件；仅监听127.0.0.1。前端为原生HTML/CSS/JS，内置Microsoft YaHei字体与现用品牌图标。登录凭据只存私有配置，浏览器使用HttpOnly会话Cookie；管理写操作校验同源，后台照片不对匿名用户开放。

`python3 scripts/deploy.py` 只检查；加`--deploy`发布到现有Studio的独立`aidog-photos`服务。新应用默认密码从本机私有偏好文件读取，在内存中派生scrypt哈希后经SSH标准输入传输，不输出明文、不打入程序包。升级保留远端现有登录配置。照片和使用记录存放在Mac Studio，GitHub存代码与分享入口。服务器数据、配置与旧`aidog-share`完全独立。

`python3 scripts/import-library.py --directory <明确的本地图片目录>`默认只检查；加`--upload`幂等入库。正式照片和私有数据不进GitHub。二维码可编辑源位于`assets/二维码/`，文字嵌入微软雅黑。

验证：`python3 -m unittest discover -s tests -v`运行隔离HTTP测试。`tests/browser.mjs`仅对本地独立QA实例运行，系统分享使用模拟，截图中的示意测试图不上传正式图库。部署与回退见[部署说明](output/deploy说明.md)。
